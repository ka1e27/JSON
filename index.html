    Exhibit C

    The six known disguises

    study these before the lineup
    String
    "hello" · "42" · ""
    Hiding inside quotes. If it wears quotes it's a string — even "42". That one gets everybody.
    Number
    42 · -7 · 3.14 · 1e3
    Bare digits, no quotes. Confident. Unbothered. Occasionally the answer to everything.
    Boolean
    true · false
    Only two outfits, always lowercase. "true" in quotes is an impostor — that's a string.
    Null
    null
    Shows up as nothing at all. Not zero. Not empty. Nothing. Deeply relatable.
    Array
    [1,2,3] · [] · [null]
    Travels in a gang, wears square brackets. Even alone. Even empty.
    Object
    {"a":1} · {}
    The classic look: curly braces and keys. Often has more objects inside. It never ends.
